This site is the **public** customer surface for Nemesis: Admin, ISSO, and contractor DBA. It is not the internal engineer handbook. Product papers and install runbooks stay in the portal repo; this site summarizes them and links by path.

The acceptance path is a **first scan you can complete from these pages**: install the lab stack, register a least-priv Postgres 16 target, queue a STIG scan, export CKL when findings exist, then record a waiver overlay.

  Install → add target → run scan → export CKL → waivers. Architecture for a reviewer is linked at the end.
</Card>

## What this site does not claim

- Production-ready on-prem, air-gap, or multi-cluster product.
- CUI, confidential STIG packages, or a standalone XCCDF dump.
- Full engine coverage (MySQL, Mongo, SQL Server, Oracle packs may exist in the engine; they are not this first-scan path).
- FedRAMP, CMMC PASS, SOC 2, or any certification.
- That empty Findings means the target is clean. If the lab-worker image was built without a GitHub token that can link `StartScan`, Findings stay empty honestly.
