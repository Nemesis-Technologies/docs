Connected Hub-pull [lab compose](/lab-ops/lab-compose) does not require a license file. Air-gap compose **does** (presence fail-closed).

## Two checks (do not skip either)

| Stage | Script | What it proves |
| --- | --- | --- |
| Presence | `airgap-license-gate.sh` | `NEMESIS_LICENSE_FILE` is a non-empty readable regular file. Missing / unset / empty / directory-mount **refuses to start**. |
| Schema + Ed25519 | `airgap-license-validate.sh` | `NEMESIS-LICENSE-V1` file, edition, instance count, `issued_at`, `org_id` and/or `binding_id`, optional `not_after` not expired, signature verifies with the public key. |

The gate always calls the validator after presence. Fail-closed on bad schema, bad signature, expired `not_after`, or missing verify key. Instance-count 20% ceiling is the control plane (`POST /api/control-plane/assets`), not this gate.

Env:

- `NEMESIS_LICENSE_FILE` — absolute or compose-relative path to the signed file
- `NEMESIS_LICENSE_VERIFY_KEY_FILE` — public verify key only. Fallback search (validator only): `<license-path>.pub` or `/run/nemesis/license.pub`

## Generate offline (`nemesis-license.sh`)

Work from `apps/self-hosted/` on a signing host (may be the connected pack host). Editions: `compliance` | `protect` | `platform`. Count must be a positive integer. You must pass `--org-id` and/or `--binding-id`.

<Steps>
  <Step title="Generate an Ed25519 keypair">
    ```bash
    chmod +x nemesis-license.sh
    ./nemesis-license.sh gen-key \
      --private /path/to/operator-held/signing.pem \
      --public /path/to/nemesis.lic.pub
    ```

    Success prints that a keypair was written. Contents are not logged. Keep the private path off git and off the IL.
  </Step>
  <Step title="Sign a license file">
    ```bash
    ./nemesis-license.sh generate \
      --key /path/to/operator-held/signing.pem \
      --edition compliance \
      --count 1 \
      --org-id "$ORG_ID" \
      --out /path/to/nemesis.lic
    ```

    Optional: `--binding-id ID`, `--not-after` as a UTC ISO timestamp. Success prints that a signed file was written. Do not `cat` the file into tickets, logs, or this site.
  </Step>
  <Step title="Validate locally">
    ```bash
    ./nemesis-license.sh validate \
      --file /path/to/nemesis.lic \
      --public /path/to/nemesis.lic.pub
    ```

    That wrapper sets `NEMESIS_LICENSE_FILE` / `NEMESIS_LICENSE_VERIFY_KEY_FILE` and runs `airgap-license-validate.sh`. Expect: `air-gap license schema+signature validated (contents not logged; no phone-home)`.
  </Step>
</Steps>

Owner / Admin `settings.manage` on a signing host can also produce a file. Same honesty: no phone-home, do not log the body.

## Air-gap start (gate + validate)

On the IL, after [pack / load](/lab-ops/air-gap):

```bash
export NEMESIS_LICENSE_FILE=/path/to/local/nemesis.lic
export NEMESIS_LICENSE_VERIFY_KEY_FILE=/path/to/local/nemesis.lic.pub
docker compose -f compose.yaml -f compose.airgap.yaml up -d --no-build --pull never
```

`compose.airgap.yaml` runs `airgap-license-gate.sh` as `license-gate` (must complete successfully) and again on `cloud` / `lab-worker` entrypoints. You can run the same checks by hand:

```bash
export NEMESIS_LICENSE_FILE=/path/to/local/nemesis.lic
export NEMESIS_LICENSE_VERIFY_KEY_FILE=/path/to/local/nemesis.lic.pub
./airgap-license-gate.sh
```

Presence-only success is not enough if the validator is missing — the gate fail-closes. Do not invent a license-server URL. Do not `curl` anything.
