An operator should be able to run **connected lab compose**, **air-gap pack / load**, and **offline license** from **this site alone**. Portal files under `apps/self-hosted/` are cited by path. They are not copied here as the home.

Compose, air-gap pack, and license on this site still cite the portal scripts. A shipped `majutsu` CLI wraps those Phase 1 flows and adds Phase 2 **GET-only** portal reads. Role-bound `nms_` tokens exist; the CLI still has no StartScan. See [CLI command × role](/self-hosted/cli-roles).

<Warning>
  **Hub-pull compose ≠ air-gap.** [`compose.yaml`](https://github.com/Nemesis-Technologies/portal/blob/144e0f9d53f815c590f9513af31150bc557a1ec5/apps/self-hosted/compose.yaml) pulls / builds on a connected host. Closed-network bring-up is [`compose.airgap.yaml`](https://github.com/Nemesis-Technologies/portal/blob/144e0f9d53f815c590f9513af31150bc557a1ec5/apps/self-hosted/compose.airgap.yaml) after `docker load`. Do not run `docker compose up --build` on an IL.
</Warning>

<Steps>
  <Step title="Bring up the connected lab">
    Single-node Docker Compose under `apps/self-hosted/`. Hub-pull path. Console + local control-plane Postgres 17 + outbound-pull `nmlw_` lab-worker. See [Lab compose](/self-hosted/lab-compose). First STIG scan after that is the [first-scan path](/first-scan/overview).
  </Step>
  <Step title="Pack for a closed network (optional)">
    On a **connected** host, run `pack-airgap.sh`, sneakernet the tarball, `docker load`, then no-pull compose. See [Air-gap pack](/self-hosted/air-gap).
  </Step>
  <Step title="Generate and validate a license">
    Offline Ed25519 file. Presence fail-closed, then schema + signature. No phone-home. See [License](/self-hosted/license).
  </Step>
</Steps>

Which tool you are holding is on the [tool family](/self-hosted/tool-family) table. `dbscanner` is the eng/lab engine CLI. `dam-proxy` is the Protect DAM daemon. Neither is the `majutsu` CLI.

## What you will have at the end

- Connected lab: console at `http://localhost:3000` from Hub-pull `compose.yaml` (not air-gap).
- Closed network (if you packed): loaded `postgres:17`, `majutsu-lab-cloud:airgap`, `majutsu-lab-worker:airgap`, started with `--no-build --pull never`.
- A signed license file plus a public verify key. Private signing key stays operator-held and off the IL.
- Scripts remain the cited compose / pack / license path. Optional: `majutsu` Phase 2 GET reads with a role-bound `nms_` token ([CLI roles](/self-hosted/cli-roles)).
